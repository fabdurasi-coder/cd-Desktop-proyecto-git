# AGENTS.md — Contrato de trabajo

Estas reglas se aplican a este proyecto y deben seguirse durante todo el trabajo:

- Háblame siempre en español. Explícame lo que haces con palabras sencillas; no sé programar.
- Antes de escribir o cambiar código, hazme las preguntas necesarias y propón un plan corto. Espera a que lo apruebe antes de empezar a programar.
- Pídeme permiso antes de instalar programas o borrar archivos.
- Si hacemos una aplicación web, debe ser sencilla, funcionar bien en celulares y usar Next.js, TypeScript y Tailwind CSS. - Construye la estructura de manera que se pueda conectar con Python en el futuro.
- Cuando termines un trabajo, dime paso a paso cómo abrirlo y probarlo en mi navegador.
- Al comenzar un proyecto nuevo, guarda una copia de este contrato en la carpeta principal del proyecto y síguelo antes de escribir la primera línea de código.
